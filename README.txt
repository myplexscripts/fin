LEDGER PORTFOLIO JOURNAL

QUICK START

1. Keep every file in this folder together.
2. Open index.html in a modern browser.
3. Your data stays in that browser unless you export a backup.

INSTALLABLE AND OFFLINE USE

For the browser's Install App option and full offline caching, Ledger must be
served from localhost or an HTTPS website. Opening index.html directly still
supports the core tracker, local saving, CSV import, and backups, but browsers
do not allow service workers on ordinary file URLs.

UPGRADING FROM THE PREVIOUS VERSION

Ledger automatically migrates existing data saved by the earlier app in the
same browser. Export a full backup before replacing a version you currently
use.

IMPORTANT CALCULATION NOTE

Record contributions and withdrawals on the date they occur. Ledger uses them
to separate investment growth from money you moved into or out of the
portfolio. Returns use the Modified Dietz method when cash flows are present.

LANGUAGE STYLE

Open Setup to switch the entire interface between plain language and standard
financial terminology. Plain language is the default for new installations.

BACKUPS

Use Data Tools to export a normal JSON backup or an encrypted .ledger backup.
Encrypted backups require the same password when restored. There is no password
recovery.
